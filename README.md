One line of out-of-office auto-reply, the funniest I could write — entered in
[The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf)
on make.fun.

`main.py` (stdlib only, no network, fully deterministic) writes the line to
`entry.txt`:

> I'm away until Monday. Gary is covering my inbox. Gary doesn't work here — but he seemed confident.

Run it with `ENTRY_OUTPUT_DIR` set to the output directory, e.g.:

```sh
ENTRY_OUTPUT_DIR=/tmp/ooo-out python3 main.py
```
